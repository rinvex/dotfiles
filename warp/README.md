# Warp tab configs

Versioned copies of the Warp tab configs that drive `bin/new-worktree`.
Install by copying (or symlinking) into `~/.warp/`:

    cp warp/tab_configs/*.toml            ~/.warp/tab_configs/
    cp warp/default_tab_configs/worktree.toml ~/.warp/default_tab_configs/

| File | Warp entry point | What it runs |
|---|---|---|
| `tab_configs/new-worktree.toml` | + menu → Tab Configs → "New worktree" | `new-worktree <repo> <base branch> <feature>` (pickers for all three) |
| `tab_configs/new-worktree-claude.toml` | + menu → Tab Configs → "New worktree + Claude" | same, then launches `claude` inside the worktree |
| `default_tab_configs/worktree.toml` | + menu → "Worktree in" → repo | `new-worktree <repo> <current branch> <auto-generated name>` |

Warp itself only knows how to run `git worktree add` under `~/.warp/worktrees`; it has no
setup hook, no cleanup and no Herd awareness. Everything after the checkout lives in the script.
